# Boundary and distinct mechanism

One atomic analysis: pinned published terms → independent whole-document fetch → independent per-unit offer/requirement compatibility matrix → exact complete-report agreement → deterministic lower/upper capacitated max-flow and min-cut witnesses → immutable root-bound result.

Callers supply no text summaries, labels, flow edges, scores or flow plans. Source quantities and terms are declared input constraints, not verified physical inventory. The artifact is the actual object analyzed, not proof that a provider performed or can perform an external service.

YES edges are present in both networks; UNKNOWN only in the possible network; NO in neither. Exact lower flow establishes a supported allocation only when every demand unit is served. An upper-flow deficit proves insufficiency even if every unknown edge became usable. Otherwise the result is AMBIGUOUS and the assured-plan interface denies access. A source acquisition/hash/schema failure is HELD, not infeasibility.

The temporary residual network is a mathematical solver structure, not a stored owner-controlled knowledge graph. No versioned graph proposals, head adoption, certificates, one-time consumption, bidder roster, price auction, payment, or mutable allocation rights exist. Snapshots are immutable queries. Max-flow capacity conservation and dual min-cut witnesses differ from a one-winner semantic auction, interval intersection, minimum set cover, Pareto selection, text partitioning and sequential likelihood accumulation. Shared fetch/signing code is infrastructure, not the novelty claim.

The nondeterministic compatibility cells are consequential: changing one YES to NO can remove a full flow; UNKNOWN yields possible edges but never unconditional support. Optimization alone cannot decide whether one declared offering covers one declared requirement. GenLayer validators independently interpret the complete text for all cells.

UI/backend: source discovery, authentication, nonauthoritative previews. Contract: acquisition, integrity, strict schema, complete semantic audit, exact consensus, both global optima and witnesses, immutable output roots. External systems: actual capacity, delivery, payment and real-world truth. No frontend or physical fulfillment is shipped. Experimental; no universal novelty or acceptance guarantee.
